# Payments SDK

Reusable TypeScript payment operations and reliable payment evidence. Paddle Billing is the first provider; PostgreSQL supplies durable storage and Get Modular integration is optional.

Implementation in progress according to [the reviewed plan](docs/implementation-plan.md). Includes monthly subscriptions and one-time purchases. Product entitlements, credit ledgers and AI usage remain application-owned.

No live Paddle credentials are required for the fixture-based end-to-end qualification.
